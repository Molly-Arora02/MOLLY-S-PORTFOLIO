## 🌟 Highlights & Features

- **🌆 Interactive 3D AI Engineer Room**:
  - Full WebGL room with real-time shadow maps, ACES filmic tone mapping, and ambient lighting.
  - **AI GPU Server Rig**: Tempered glass liquid-cooled rig with spinning RGB fans and 3 AI Tensor GPUs.
  - **Floating 3D Holographic Core**: Wireframe icosahedron with pulsing inner plasma and orbital rings.
  - **Ambient Cyber Motes**: Floating 3D light particles gently drifting through space.
  - **Animated Coffee Mug**: Real-time GLSL Perlin noise steam shader.

- **🎲 Dedicated 3D Rubik's Cube Plinth**:
  - Positioned on a sci-fi hexagonal pedestal with zero monitor overlap.
  - Interactive face slice rotations ($U, D, L, R, F, B$), Scramble, and Reset Solved algorithms.
  - Interactive sticker click raycasting revealing verified skills and credentials.

- **🖥️ Dual Ultra-Wide Workstation Monitors**:
  - Live display for shipped products: **MUSE AI** (Agora Voice AI), **Focus Forge**, **Satyadarshi**, and **Phantom Mesh**.
  - Verified badges for **Rank 8 PAN India @ DevSummit 2026**, **Google Prompt Engineering Certification**, **IIT Mandi (8.0 CGPA)**, and **Stanford Code in Place**.

- **🎨 Wall Whiteboard**:
  - Live drawing canvas with multiple marker colors, eraser, clear tools, and pre-loaded diagrams (Neural Networks & Balanced BSTs).

- **🕹️ Playable Retro Arcade Cabinet**:
  - 3 classic arcade mini-games rendered onto a CRT screen with scanlines:
    1. 🐍 **Cyber Snake**
    2. 🧱 **Quantum Tetris**
    3. 🚀 **Space Invaders**

- **🎵 Web Audio Synthesizer**:
  - Procedural Lo-Fi ambient music generator, whooshes, mechanical keyboard clicks, and 8-bit retro arcade tones.

- **♿ Accessible 2D Portfolio Mode**:
  - Instant toggle between the 3D room experience and a fast scrolling 2D portfolio layout for mobile and quick reading.

## 🛠️ Tech Stack

- **3D Graphics & Shaders:** Three.js, Custom GLSL Shaders, WebGL
- **Animation & Choreography:** GSAP (GreenSock)
- **Audio Engine:** Web Audio API Procedural Synthesizer
- **Frontend & Tooling:** Vanilla JavaScript (ES6+), Vite, HTML5 Canvas, Modern CSS Glassmorphism
- **Effects:** Canvas Confetti, Custom Particle Buffers

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Molly-Arora02/MOLLY-S-PORTFOLIO.git
cd MOLLY-S-PORTFOLIO
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```
Open **`http://localhost:5173`** in your browser.

### 4. Build for production
```bash
npm run build
```
